# Processing Pipeline

This directory will contain reproducible tooling for:

1. acquiring REMA and LIMA source data,
2. validating CRS and metadata,
3. cropping to region definitions,
4. generating terrain representations,
5. generating imagery tiles,
6. writing provenance metadata.

Preferred tooling for initial experiments: GDAL plus small Python or shell scripts.

The first target region is `regions/ferrar-glacier.json`.
