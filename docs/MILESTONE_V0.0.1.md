# v0.0.1 — Ferrar Glacier

## Goal

Build one excellent, reproducible 3D Antarctic scene from open data and determine whether the experience is compelling enough to expand.

## Acceptance criteria

- Matching REMA and LIMA data acquired for the Ferrar Glacier footprint
- Terrain and imagery align correctly in 3D
- Local browser viewer supports smooth orbit, tilt, zoom, and flight
- Vertical exaggeration control works
- Simulated sun / hillshade control works
- Layer attribution and provenance are visible
- REMA 10 m prototype can be upgraded to REMA 2 m without redesigning the scene architecture
- Another contributor can reproduce the scene from repository instructions without access to private/commercial data
